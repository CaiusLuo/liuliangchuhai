# Contributing

1. Start from a scoped GitHub Issue and create a feature branch.
2. Keep changes within the Issue and repository architecture boundaries.
3. Add focused tests, run relevant checks and `make check` when applicable.
4. Open one PR linked to the Issue with concise, factual verification evidence.
5. Wait for CI and maintainer review. Only `@CaiusLuo` merges into `main`.

Contributors do not need upstream write access. Ask before changing a frozen
Domain, Application, or public API contract, or expanding an Issue's scope.
